# Build customer intelligence into your product

Northstar is a **fictional** customer engagement platform built to demonstrate a complete developer documentation experience in Mintlify. It helps teams create customer records, collect product events, and review adoption.

<Note>
  This is a documentation demo, not a real hosted SaaS product. `api.northstar.example` is intentionally fictional. The starter kit includes an optional local mock server.
</Note>

## What can you build?

| Capability | Common use case |
| --- | --- |
| [Customers](/api-reference/customers/list-customers) | Map your CRM or application accounts to Northstar records |
| [Events](/guides/event-tracking) | Track logins, feature usage, and key adoption milestones |
| [Analytics](/guides/usage-analytics) | Summarize engagement for a customer over time |
| [Webhooks](/guides/webhooks) | Register subscriptions for lifecycle changes |

## Core API conventions

- Base path: `/v1`.
- Authentication: `Authorization: Bearer YOUR_API_KEY`. See [Authentication](/guides/authentication).
- Request and response bodies: JSON.
- Paginated list results: `data` with a `pagination` object. See [Pagination and rate limits](/guides/pagination).
- Error responses: a stable `error.code`, human-readable `error.message`, and `request_id`. See [Troubleshooting](/guides/troubleshooting).

<Warning>
  For an actual working playground, select the local mock server in the API server selector while `python3 mock_api.py` is running on your machine. A published site cannot access a mock running only on your laptop from other people's browsers.
</Warning>
